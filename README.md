
# TypeScript Assignment

## Assignment Overview

This repository contains my TypeScript assignment solutions and two technical blog posts. The assignment focuses on TypeScript fundamentals, including functions, union types, tuples, generics, interfaces, classes, access modifiers, and asynchronous programming.

## Coding Solutions

All coding problems are implemented in a single TypeScript file:

- `solutions.ts`

### Topics Covered
- Optional and default parameters
- Union types and type narrowing
- Readonly tuples
- Generic functions
- Interfaces and array methods
- Generics with `keyof`
- Classes and inheritance
- Access modifiers
- Promises and asynchronous functions

## Blog Posts
